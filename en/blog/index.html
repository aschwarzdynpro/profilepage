Translation Studio · new

Three languages, one zip file, and nobody sees what is missing

Dataverse keeps every label per language. If a translation is missing, French users see English field names. The standard way to fix that is an export to Excel with thousands of rows and no filter for “missing”. Translation Studio reads the same export, shows only the gaps and writes it back filled in.
